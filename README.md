# Quantum-Feedback-Simulation
这是我用Matlab对我所要进行的量子反馈实验的模拟，在该模拟中我构造了光学体系，我采用实验室通过1MHz采集卡采集到的四波混频生成的有量子纠缠性质的双模强度差压缩光的原始数据作为光源，人为引入磁力计环境，初始的磁场和磁场微扰，由于存在拉莫尔进动，进入原子池的双模压缩光会带上磁场信息，提取一路光模拟锁相放大器对其进行调制解调操作，经过放大器再将其对另外一路进行延时地反馈（构造合理的低通和电子学延时以及电子学噪声），再将反馈得到的信号与相干光的标准量子极限做对比。
coh1.xlsx和sqz1(7dB).xlsx分别是相干光和压缩光经过高量子效率探头的光电探测器接收到的强度信号，作PSD处理后它们的强度差压缩度在0.5-1MHz范围内可达7dB。
